# Registro de uso de inteligencia artificial

**Estudiante:** Gabriel Rivas  
**Asignatura:** ICINF1107  
**Evaluación:** N.º 4 — Portafolio React

## 1. Herramienta utilizada

Durante el desarrollo de esta evaluación utilicé ChatGPT como herramienta de apoyo.

Lo utilicé principalmente para comprender conceptos de React, organizar el trabajo, revisar código y recibir orientación durante la migración de mi portafolio.

## 2. Objetivo de utilizar inteligencia artificial

Mi principal objetivo fue recibir apoyo técnico para transformar mi portafolio original, desarrollado con HTML y CSS, en una aplicación construida con React y TypeScript.

También busqué comprender el propósito de cada modificación, en lugar de limitarme a copiar código sin conocer su funcionamiento.

## 3. Actividades realizadas con apoyo de IA

Utilicé inteligencia artificial para recibir orientación en las siguientes actividades:

- Migración de HTML a JSX.
- Adaptación de estilos CSS.
- Implementación de React Router.
- Uso de `useState` para administrar estados.
- Implementación de filtros de proyectos.
- Consumo de la API REST de GitHub.
- Uso de `useEffect` y `AbortController`.
- Implementación de Context API.
- Preparación de documentación técnica.

## 4. Ejemplos de consultas realizadas

Durante el proceso realicé consultas relacionadas con:

**API REST:**

Solicité orientación para consultar mis repositorios públicos mediante la API de GitHub y mostrar sus datos.

**Context API:**

Pedí ayuda para implementar un contexto global sin modificar los colores ni la estética de mi portafolio.

**Documentación:**

Solicité apoyo para estructurar y redactar la documentación técnica de la evaluación.

## 5. Revisión crítica de las respuestas

No todas las propuestas generadas por inteligencia artificial funcionaron exactamente como necesitaba.

Problema que apareció al implementar un tema oscuro mediante Context API.

Esta modificación afectó los colores y la estética general de mi portafolio, por lo que decidí revertir esos cambios.

Posteriormente, implementé Context API para compartir información relacionada con GitHub sin modificar la apariencia de las páginas.

Estas experiencias me permitieron comprender la importancia de revisar las propuestas antes de incorporarlas definitivamente.

## 6. Aprendizajes y responsabilidad personal

Considero que la inteligencia artificial fue útil para avanzar en el desarrollo y comprender diferentes conceptos técnicos.

Sin embargo, también comprobé que sus respuestas pueden introducir modificaciones innecesarias o diferentes a los requisitos originales.

Por este motivo, prioricé revisar el código, comparar los resultados con mi portafolio anterior y comprobar la compilación.

Ejecuté `npm run build` y obtuve resultados correctos.

Mi principal aprendizaje fue que la inteligencia artificial puede facilitar el desarrollo, pero es necesario mantener un criterio propio, verificar las soluciones y comprender el funcionamiento del código.

Asumo la responsabilidad de revisar y entregar el proyecto final.
